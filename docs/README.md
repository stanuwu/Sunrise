# Sunrise technical notes

This directory explains the internal systems that let Sunrise run an older Destiny 2 build in an
offline environment.

- [Client integration](client-integration.md) explains how the replacement DLL, process hooks, and
  local services work together.
- [Local gameplay and mission scope](local-gameplay-and-missions.md) explains the current gameplay
  host and the work needed to support mission encounters.

These notes describe the current source tree. They do not describe supported player features.
For feature status and build instructions, read the repository [README](../README.md).
